# -Smart-Air-quality-Monitoring-
Arduino-based air quality monitor uses MQ135 to detect CO2, smoke, ammonia &amp; harmful gases, DHT11 for temperature &amp; humidity, and 16x2 LCD to display live PPM values. It alerts via buzzer when air is poor, ensuring healthy environment for homes, labs &amp; industries.  

## Components Used

The Smart Air Quality Monitoring system uses the following hardware components:

* **Arduino Uno** – Processes sensor readings and controls the system.
* **MQ135 Gas Sensor** – Detects changes in air quality and the presence of certain gases.
* **DHT11 Sensor** – Measures temperature and humidity.
* **16×2 LCD Display** – Displays real-time sensor readings.
* **Buzzer** – Provides an alert when air quality crosses the configured threshold.
* **Connecting Wires and Breadboard** – Used to connect the components.

## Working Principle

1. The MQ135 sensor monitors changes in air quality.
2. The DHT11 sensor measures the surrounding temperature and humidity.
3. The Arduino Uno reads the sensor values and processes the data.
4. The LCD displays the readings for real-time monitoring.
5. When the configured air-quality threshold is exceeded, the buzzer alerts the user.

## Applications

* Indoor air-quality monitoring in homes and offices.
* Air-quality observation in laboratories and classrooms.
* Basic environmental monitoring in small industrial settings.
* Educational projects for learning sensor interfacing and embedded systems.
